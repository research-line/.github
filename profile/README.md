# research-line

**Open-access research repositories with papers, computational notebooks, and reproducibility material.**

research-line collects public research work across mathematical physics, cosmology, computational medicine, AI-society studies, and research software.
The repositories are intended for inspection, citation, replication, and follow-up research; they are not medical, financial, legal, or investment advice.

## Start Here

| Need | Start with | Why |
|---|---|---|

| The RFEP bridge paper and code | [rfep-framework](https://github.com/research-line/rfep-framework) | Renormalized Free-Energy Principle context and Zenodo-linked material |

## How To Read These Repositories

- Prefer the repository README and `CITATION.cff` where present for current citation and status information.
- Treat Zenodo DOI records as archival publication records and GitHub as the live code/documentation surface.
- Check each project for explicit status notes before interpreting a claim as established, conditional, exploratory, or superseded.
- Use [`research-line/.github/llms.txt`](https://github.com/research-line/.github/blob/main/llms.txt) for machine-readable ecosystem context.
